# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅ Yes    |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately to the maintainers with:
- A clear description of the issue and affected component (`server/`, `app/`, or `deploy/`).
- Steps to reproduce or a minimal proof-of-concept.
- Potential impact assessment.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure and patch.
